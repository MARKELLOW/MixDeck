# MixDeck

Звуковой микшер для Windows 10 версии 2004 и новее и Windows 11 (x64). Разработчик — **MARKELLOW**.

[**Скачать MixDeck для Windows x64**](https://github.com/MARKELLOW/MixDeck/releases/latest/download/MixDeck-portable.zip)

## Возможности

- Отдельная громкость, отключение звука и горячие клавиши для приложений.
- Встраивание звука нескольких приложений в виртуальный микрофон с отдельной громкостью каждого источника.
- Саундпад со звуковой волной, перемоткой и запуском файлов по биндам.
- Проверка микрофона и вывод звука на несколько устройств с разной громкостью.

## Первый запуск

1. Скачай и распакуй `MixDeck-portable.zip`. Оставь папку `Утилиты` рядом с `MixDeck.exe`.
2. Для виртуальных аудиоустройств один раз запусти установщик USB/IP из папки `Утилиты/MixDeck Virtual Audio`. Если установщик попросит перезагрузить Windows, перезагрузи компьютер.
3. Запусти `MixDeck.exe`, дождись подключения виртуальных устройств и выбери наушники и микрофон во вкладке «Устройства».
4. Чтобы передавать звук в голосовой чат, выбери **MixDeck Microphone** в настройках микрофона программы для общения. В MixDeck отметь нужные приложения на вкладке «Встраивание звука».

Подробная инструкция есть в `README.txt` внутри архива. Вопросы и предложения можно оставить в [Issues](https://github.com/MARKELLOW/MixDeck/issues).
